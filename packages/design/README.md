# Shiv UI

Shared warm-concrete, amber and ink tokens from Master Plan §2. Web components
use CSS Modules and rem units; native screens consume `@shiv/design/tokens`.
Hindi body copy uses the Mukta fallback, line height at least 1.5. Money uses
shared integer-paise formatting and tabular figures. Controls are at least 44px,
primary fields/buttons 48px. Body text is at least 1rem; utility text never below
.875rem. Focus rings use blue, 3px. Ink3 is disabled-only. Light mode only.
Web components accept translated labels; no visible English defaults live here.
